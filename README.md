# Addelio

Addelio is a Mac email client for Gmail.

This repository holds **releases and public bug reports only**. Addelio's source code is not here.

## Download

**[Download Addelio for Mac](https://addelio.com/download)** (Apple silicon)

Every build is signed with a Developer ID and notarised by Apple. Addelio checks for updates once a day and installs them only when you choose **Restart to update**. You can turn the daily check off in Settings ▸ About.

Release notes for each version are on the [Releases](https://github.com/adatoo/addelio-public/releases) page.

## Report a problem

> **This is a public page. Never post email content here.** That means no message text, email addresses, subjects, attachments or screenshots of your inbox.

- **Bugs and feature ideas:** [open an issue](https://github.com/adatoo/addelio-public/issues/new/choose). The form asks for the Addelio and macOS versions and the steps to reproduce.
- **Anything private** (a problem with a particular message, or anything involving your account): email **support@addelio.com**, or use **Help ▸ Report a Problem…** in Addelio. That attaches a diagnostics report with no addresses, subjects or tokens.
